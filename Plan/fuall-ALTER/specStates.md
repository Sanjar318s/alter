# ALTER — Пустые и ошибочные состояния (specStates.md)

> Дополнение к specWEBDizain.md и specAppDizain.md. Перечисляет состояния экранов, которые
> не были отрисованы в основных макетах (пустой контент, ошибка сети, ошибка загрузки,
> состояние "в процессе").
> Компонент-основа везде одна: **corner-marks-рамка без содержимого** + короткий mono-текст +
> primary-кнопка действия (см. specAppDizain.md §5 «Пустые состояния»).

---

## 1. Общий паттерн

```
[ Рамка с corner marks, внутри — иконка-моноширинный символ (не иллюстрация) ]
[ Заголовок Syne 20px ]
[ Подпись Space Grotesk 14px, ink-70 ]
[ Primary-кнопка (если есть осмысленное действие) ]
```

Три типа состояния, разное поведение:

| Тип | Когда | Amber/Magenta | Retry |
|---|---|---|---|
| **Пусто** (нет данных) | Новый пользователь, ещё нечего показывать | нейтральный line | Нет — только CTA к действию |
| **Ошибка** (сеть/сервер) | Запрос не выполнен | amber-обводка рамки | Кнопка «Повторить» |
| **Загрузка** (skeleton) | Данные ещё грузятся | — | — (skeleton-блоки, не спиннер, см. specWEB.md §2) |

## 2. По экранам — веб

| Экран | Пусто | Ошибка |
|---|---|---|
| Profile Hub — Билды | «Пока нет ни одного билда» + кнопка «Добавить билд» (свой профиль) / просто текст (чужой) | «Не удалось загрузить билды» + «Повторить» |
| Profile Hub — Истории | «Здесь появятся истории о процессе» + CTA (свой) | то же, «Повторить» |
| Explore | «По этим фильтрам ничего не найдено» + кнопка «Сбросить фильтры» | «Explore временно недоступен» + «Повторить» |
| Maker Studio — колонка kanban | «Нет заказов на этом этапе» (нейтрально, это нормальное состояние, без иконки ошибки) | «Не удалось загрузить доску» + «Повторить», сама доска не рендерится |
| Публичная страница коммишена | Если статус «закрыт»: форма скрыта, вместо неё «Коммишены сейчас закрыты» + опция «Уведомить, когда откроются» (email/push, если пользователь залогинен) | — |
| Уведомления | «Пока нет уведомлений» | «Не удалось загрузить уведомления» + «Повторить» |

## 3. По экранам — приложение

Те же случаи + мобильно-специфичные:

| Экран | Пусто/ошибка |
|---|---|
| Лента/Explore | Pull-to-refresh корректно возвращает контент из ошибочного состояния (не только кнопка) |
| Офлайн (нет сети) | Отдельное состояние, отличное от «ошибка сервера»: баннер сверху «Нет соединения — показаны сохранённые данные», кэш из React Query отображается вместо ошибки там, где кэш есть |
| Загрузка фото не удалась | Карточка билда/истории остаётся в ленте создания с overlay «Не отправлено» + иконка retry на самой карточке (не отдельный полноэкранный экран) |
| Maker Studio — свайп-действие сорвалось (нет сети) | Карточка возвращается в исходную колонку с анимацией отката + toast «Не удалось обновить статус» |
| Push пришёл, а объект уже удалён/недоступен (deep link в никуда) | Экран-заглушка «Этот заказ/профиль больше недоступен» + кнопка «На главную», не краш и не белый экран |

## 4. Формулировки (тон)

Коротко, по-деловому, без «Упс!» и извинений-клише. Примеры:
- Пусто: `ЗДЕСЬ ПОКА ПУСТО` (mono, uppercase) + обычным текстом причина/действие
- Ошибка: `НЕ УДАЛОСЬ ЗАГРУЗИТЬ` + «Повторить»
- Офлайн: `НЕТ СЕТИ` + «Показаны сохранённые данные»

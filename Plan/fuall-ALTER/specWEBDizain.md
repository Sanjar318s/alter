# ALTER — Дизайн-спецификация сайта (specWEBDizain.md)

> Дизайн-система + расположение элементов по каждой странице сайта.
> Следующий шаг после этого файла — визуальные макеты (по команде).

---

## 1. Направление

**Тема: «Backstage» — закулисье фотосессии/сцены.** Не лента, а студия: маркеры кадрирования, гели прожекторов, модель-листы фотографов. Косплей — это ремесло и перформанс одновременно, дизайн должен читаться и как *мастерская* (Maker Studio — шитьё, замеры, чертежи), и как *сцена* (профиль, портфолио, свет).

Осознанно ухожу от AI-дефолтов: не кремовый+терракота, не голый чёрный+один кислотный акцент, не хайрлайн-газетная вёрстка. Вместо одного акцента — **дуотон** (два цветных геля прожектора одновременно), это отличает от «чёрный фон + один яркий цвет».

## 2. Токены дизайн-системы

### Цвет
| Токен | HEX | Роль |
|---|---|---|
| `--ink` | `#12101A` | Базовый фон (тёплый почти-чёрный, с фиолетовым подтоном, не чистый #000) |
| `--stage` | `#1D1A29` | Фон карточек/панелей поверх ink |
| `--paper` | `#F2EEE9` | Текст на тёмном / фон светлых зон (форм, модалок) |
| `--magenta` | `#E5487A` | Акцент №1 — гель прожектора, primary actions, статус «открыт» |
| `--amber` | `#F2A93B` | Акцент №2 — второй гель, вторичные акценты, предупреждения/дедлайны |
| `--line` | `#3A3550` | Тонкие разделители, обводки полей |

Дуотон используется как направленный градиент только в героях и на статус-индикаторах — не размазан по всему интерфейсу (иначе превращается в шум).

### Типографика
| Роль | Шрифт | Где |
|---|---|---|
| Display | **Syne** (Bold/ExtraBold) | Заголовки, крупные цифры, имя мейкера на публичной странице |
| Body | **Space Grotesk** | Основной текст, кнопки, навигация |
| Utility/Mono | **Space Mono** | Статусы заказов, дедлайны, ценники, метаданные — «этикеточный» слой |

Шкала: 12 / 14 / 16 / 20 / 28 / 40 / 64px, шаг не строго геометрический — подобран под реальные заголовки страниц.

### Layout
- Сетка 12 колонок, максимальная ширина контента 1240px, поля — свободнее к краям (не densely-packed newspaper).
- Скругления: 4px на мелких элементах (бейджи, поля), 0px на фото и карточках-«кадрах» (см. сигнатурный элемент) — фото должны выглядеть как отпечатки, а не как soft-UI.

### Сигнатурный элемент
**Уголки кадра (corner marks).** У каждой фотографии, карточки билда и превью коммишена — четыре тонких L-образных штриха по углам (как рамка визирования на фотоплёнке/модель-листе), в цвете magenta или amber в зависимости от контекста (magenta = открытый коммишен/активный билд, amber = дедлайн/ожидание). Это единственный декоративный мотив, который повторяется везде — считывается как фирменный знак ALTER, а не украшение.

## 3. Расположение по страницам

### 3.1 Landing
```
[ Nav: логотип ALTER · Исследовать · Мейкерам · Войти / Создать профиль ]
[ HERO: дуотон-градиент magenta→amber на фоне ink,
  крупный тезис (Syne 64px) + подзаголовок,
  справа/снизу — живой пример карточки профиля с corner marks ]
[ Блок «Один профиль вместо пяти сервисов» — 3 колонки: Instagram/Patreon/Etsy → зачёркнуты, ALTER → галка ]
[ Демо Profile Hub — скриншот-макет с подписями по частям интерфейса ]
[ Демо Maker Studio — kanban-доска, акцент на «депозит подтверждён» ]
[ Блок «Для кого» — 3 карточки: Косплеер / Мейкер / Фотограф, у каждой corner marks своего цвета ]
[ Footer: ссылки, соцсети, язык интерфейса ]
```

### 3.2 Profile Hub (`/u/[username]`)
```
[ Header профиля: аватар (с corner marks), имя (Syne), роли-бейджи, статус коммишена крупным mono-лейблом ]
[ Панель ссылок (Patreon/принт-шоп/соцсети) — горизонтальный ряд иконок-кнопок ]
[ Таб-переключатель: Билды | Истории | О себе ]
  -- Билды: сетка карточек-«кадров» (фото + персонаж/франшиза + дата)
  -- Истории: вертикальная лента коротких постов
[ Плашка «Конвенты» — список ближайших мероприятий текстом, справа дата ]
[ Sticky-кнопка снизу на мобильном: «Запросить коммишен» (если открыт) ]
```

### 3.3 Explore / Discovery
```
[ Верхняя панель фильтров: роль · статус коммишена · франшиза · страна — чипы, не выпадающие простыни ]
[ Блочные подборки заголовками-mono: «НОВЫЕ БИЛДЫ» / «ОТКРЫТЫЕ КОММИШЕНЫ» / «ПО ФРАНШИЗЕ» ]
[ Внутри каждой подборки — горизонтальный скролл карточек с corner marks ]
[ Поиск — отдельная строка сверху, не смешана с фильтрами ]
```

### 3.4 Публичная страница коммишена + форма запроса
```
[ Header мейкера: имя, статус (magenta = открыт / серый = закрыт), цена «от», срок ]
[ Галерея примеров работ — крупные фото с corner marks ]
[ Блок условий: коротко текст договора/правил ]
[ Форма запроса (справа на десктопе / снизу на мобильном, wizard-шагами):
   1. Тип работы  2. Референсы (загрузка)  3. Замеры (шаблон)  4. Срок и бюджет  5. Подтверждение условий ]
[ После отправки — экран-подтверждение mono-стилем: «Заявка №… отправлена» ]
```

### 3.5 Maker Studio (`/studio`)
```
[ Верх: сводка mono-цифрами — заказов в работе / просрочки / средний чек ]
[ Kanban: Новая → Обсуждение → В работе → Примерка/правки → Готово → Отправлено ]
  -- Карточка заказа: клиент, миниатюра референса, дедлайн (amber, если близко), статус депозита
[ Правая панель (при клике на карточку): чек-лист этапов, заметки, шаблон договора, кнопка «Отметить оплату депозита» ]
[ Календарь загруженности — отдельная вкладка, простая сетка недель с плотностью заказов ]
```

## 4. Компоненты (сквозные)

- **Статус-бейдж** (mono, uppercase, 12px): `ОТКРЫТО` (magenta bg) / `ЗАКРЫТО` (line bg) / `ЛИСТ ОЖИДАНИЯ` (amber bg)
- **Карточка-кадр**: фото 4:5, corner marks по углам, подпись снизу (Syne 16, mono-метаданные 12)
- **Кнопка primary**: заливка magenta→amber дуотон-градиент, текст paper, без скругления >4px
- **Поле формы**: подчёркивание line, фокус — magenta, без «пилюль»-инпутов

---

## 5. Доступность и адаптивность дизайна

- Контраст текста на `--ink`/`--stage` — не ниже AA (paper на ink уже проходит; проверить magenta-на-ink для мелкого текста, при необходимости светлее оттенок для текста)
- Видимый keyboard focus — outline amber 2px
- Уважение `prefers-reduced-motion` — corner marks и градиенты без анимации при этом флаге
- На мобильном kanban Maker Studio превращается в табы-колонки (свайп), а не горизонтальный скролл всех колонок разом
